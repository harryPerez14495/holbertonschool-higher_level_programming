# Python - Input/Output

This project covers reading and writing UTF-8 text files,
using the with statement, and working with JSON serialization.

## Topics

- Reading text files.
- Writing and appending text.
- Managing files with the with statement.
- Converting Python objects to JSON.
- Converting JSON to Python objects.
- Saving and loading data.

## Files

- 0-read_file.py: Reads a UTF-8 text file and prints its contents.
