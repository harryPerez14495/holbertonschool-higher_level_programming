MyList tests
============

Load the class:

>>> MyList = __import__("1-my_list").MyList

Check inheritance:

>>> issubclass(MyList, list)
True

Create an empty list:

>>> items = MyList()
>>> print(items)
[]

Check append independently:

>>> items.append(3)
>>> print(items)
[3]
>>> items.append(1)
>>> print(items)
[3, 1]
>>> items.append(2)
>>> print(items)
[3, 1, 2]

Print sorted values without changing the original:

>>> items.print_sorted()
[1, 2, 3]
>>> print(items)
[3, 1, 2]

Check an empty list:

>>> MyList().print_sorted()
[]

Check negative numbers and duplicates:

>>> numbers = MyList()
>>> numbers.append(-2)
>>> numbers.append(4)
>>> numbers.append(-5)
>>> numbers.append(4)
>>> numbers.print_sorted()
[-5, -2, 4, 4]
>>> print(numbers)
[-2, 4, -5, 4]

Check an already sorted list:

>>> MyList([1, 2, 3]).print_sorted()
[1, 2, 3]

Check a single element:

>>> MyList([7]).print_sorted()
[7]

Check the return value:

>>> result = items.print_sorted()
[1, 2, 3]
>>> print(result)
None
