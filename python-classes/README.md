# Python - Classes and Objects

This project introduces object-oriented programming in Python.

## Topics

- Classes and objects
- Instance attributes
- Public and private attributes
- Initialization with __init__
- Properties, getters, and setters
- Square area calculation and printing

## Tasks

- 0-square.py: Define an empty Square class.
- 1-square.py: Add a private size attribute.
- 2-square.py: Validate the size.
- 3-square.py: Calculate the area.
- 4-square.py: Access and update the size.
- 5-square.py: Print the square.
- 6-square.py: Add position coordinates.
